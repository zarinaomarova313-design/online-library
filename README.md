# Online Library System

## Жоба туралы

Online Library System — PHP және MySQL технологиялары арқылы әзірленетін онлайн кітапхана веб-қосымшасы. Жүйе пайдаланушыларға кітаптар каталогын көруге, кітаптарды іздеуге және жеке аккаунт арқылы жүйеге кіруге мүмкіндік береді.

## Жобаның мақсаты

Кітаптар туралы мәліметтерді бір жерде сақтау, кітап іздеу процесін жеңілдету және пайдаланушыларға ыңғайлы веб-интерфейс ұсыну.

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу және жүйеге кіру
- Кітаптар тізімін көру
- Жаңа кітап қосу
- Кітап мәліметтерін өңдеу және жою
- Кітаптарды атауы немесе авторы бойынша іздеу
- Кітаптарды санат бойынша сүзу
- Пайдаланушы профилі
- Деректерді тексеру және қауіпсіз сақтау

## Қолданылатын технологиялар

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- PDO

## Дерекқор

Жобада кемінде 3 кесте болады:

1. `users` — пайдаланушылар
2. `books` — кітаптар
3. `categories` — кітап санаттары

## Жоба беттері

- `index.php` — басты бет
- `books.php` — кітаптар каталогы
- `register.php` — тіркелу
- `login.php` — жүйеге кіру
- `add_book.php` — кітап қосу
- `edit_book.php` — кітапты өңдеу
- `profile.php` — пайдаланушы профилі

## Қауіпсіздік

- Парольдерді `password_hash()` арқылы сақтау
- SQL инъекциясынан prepared statements арқылы қорғану
- Шығыс деректерін `htmlspecialchars()` арқылы өңдеу
- Сервер жағында енгізілген деректерді тексеру
- Сессия арқылы пайдаланушыны аутентификациялау
