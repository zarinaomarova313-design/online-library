
# Жобаның жоспары

## 1. Жобаның атауы

Online Library System — онлайн кітапхана жүйесі.

## 2. Жобаның мақсаты

PHP және MySQL арқылы кітаптарды басқаруға, іздеуге және пайдаланушылардың аккаунттарын ұйымдастыруға арналған веб-қосымша әзірлеу.

## 3. Мәселе

Кітаптар туралы мәліметтерді қолмен сақтау және қажетті кітапты іздеу көп уақыт алуы мүмкін. Бұл жүйе кітаптар каталогын орталықтандырып, ақпаратты жылдам табуға мүмкіндік береді.

## 4. Пайдаланушылар

- Қонақ: кітаптар тізімін қарап, іздей алады.
- Тіркелген пайдаланушы: жүйеге кіріп, жеке профилін пайдалана алады.
- Әкімші: кітаптарды және санаттарды басқара алады.

## 5. Негізгі функционалдық талаптар

1. Тіркелу, кіру және жүйеден шығу.
2. Кітаптар тізімін көрсету.
3. Кітап қосу, қарау, өңдеу және жою.
4. Атауы немесе авторы бойынша іздеу.
5. Санат бойынша сүзу.
6. Деректерді серверде тексеру.
7. Пайдаланушының рұқсаттарын тексеру.

## 6. Функционалдық емес талаптар

- Интерфейс түсінікті және адаптивті болуы керек.
- Парольдер хэш түрінде сақталуы керек.
- SQL сұраныстары қауіпсіз орындалуы керек.
- Қате деректерге түсінікті хабарламалар берілуі керек.
